# Spectify — Design System Landing Page

Responsive front-end recreation inspired by the supplied visual reference. The page uses a dark charcoal canvas, violet and indigo gradients, subtle pink accents, geometric typography, product mockups and layered UI cards.

## Run locally
1. Extract the ZIP archive.
2. Open the folder in Visual Studio Code.
3. Use the Live Server extension, or open `index.html` directly in a modern browser.

## Project files
- `index.html` — semantic page structure and content sections.
- `styles.css` — theme, responsive layouts, product mockups and hover states.
- `script.js` — mobile navigation, copy interaction and GSAP/ScrollTrigger animations.
- `assets/favicon.svg` — matching tab icon.

## Included details
- Sticky, translucent navigation bar.
- Mobile navigation with animated hamburger/close state, outside-click and Escape-key handling.
- Fluid typography and layouts for mobile, tablet and desktop.
- GSAP entrance animations and ScrollTrigger reveal effects.
- Reduced-motion support via `prefers-reduced-motion`.
- CSS-built product interface illustrations and inline typographic symbols.

## External resources
Google Fonts and GSAP are loaded from CDNs, so an internet connection is required for those resources. The decorative mockups are built with HTML and CSS and do not need image downloads. Replace placeholder brand names, testimonials and the sample contact email before publishing commercially.
